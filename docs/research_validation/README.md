# Trend Following Study — Research Contract

The current repository tree contains only the 56,644-configuration QQQ/cash
study. See [the operating contract](gap_hold_flags_v5.md) and the
[project entry point](../../README.md).

The 2001–2011 development sweep, validation of its nine sealed finalists
(2012–2015) and historical evaluation of the single sealed validation winner
(2016–May 28, 2026) have completed. The locked daily EMA200/EMA100 winner uses
5.5/2.5-hour entry/exit waits and remains unchanged across all four historical
cost scenarios. Historical OOS is retrospective, not untouched or live evidence;
lower historical drawdown did not establish superiority over buy-and-hold.
